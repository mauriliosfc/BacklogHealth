How to generate a PAT
  1. Go to dev.azure.com and sign in
  2. Click your profile icon (top right)
  3. Select Personal Access Tokens
  4. Click New Token
  5. Set permissions: Work Items (Read), Project and Team (Read)
  6. Click Create and copy the token
Tip: set a 1-year expiry and note the renewal date.
Security Note: Your PAT is stored locally in config.json on your device only. It is never sent to any external service other than Azure DevOps.
